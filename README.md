# Mortality Explorer

Full-stack data application for exploring mortality data with time series analysis and ML.

[![CI](https://github.com/ndumbe0/mortality-explorer/actions/workflows/ci.yml/badge.svg)](https://github.com/ndumbe0/mortality-explorer/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features
- Time series visualization, age/sex breakdown, country comparison
- ML: forecasting, anomaly detection, clustering
- Choropleth map support (free topojson)
- Data ingestion and bring-your-own-data
